# Avaliação 1 - 2ESAN

Repositório para a Avaliação 1 da turma 2ESAN. Contém materiais e informações dos participantes e arquivos relacionados à entrega da avaliação.

## Sobre
Este repositório serve como entrega da Avaliação 1 (avalia1) para a turma 2ESAN. Atualmente contém um arquivo de participantes com a lista dos membros do grupo.

## Estrutura do repositório
- `participantes.md` — tabela com os nomes dos participantes e seus RAs.

> Observação: este repositório pode ser apenas um repositório-base/placeholder para a avaliação. Atualize a estrutura quando adicionar código, relatórios ou outros recursos.

## Como usar / contribuir
1. Clone o repositório:
   git clone https://github.com/Gabriel-Garai/Gabriel-Garai-avalia1-2ESAN.git

2. Atualize a lista de participantes:
   - Abra `participantes.md` e adicione linhas à tabela no formato:
     | Nome | RA |
     - Siga o cabeçalho já presente no arquivo.

3. Para adicionar arquivos da avaliação (ex.: código, relatório, slides), crie pastas claras como:
   - `code/`
   - `report/`
   - `slides/`
   E faça commits com mensagens descritivas.

## Boas práticas de entrega
- Inclua um arquivo `README.md` por subprojeto (se houver).
- Se a avaliação requer execução de código, inclua instruções claras de instalação e execução (ex.: dependências, comandos).
- Use commits pequenos e mensagens descritivas (ex.: "Adicionar implementação do exercício 1").
